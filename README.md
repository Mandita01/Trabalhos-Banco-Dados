# Trabalhos-Banco-Dados

Repositório centralizado com os principais projetos, análises e materiais desenvolvidos em Banco de Dados e Análise de Dados.

## 📌 Visão geral

Este repositório tem como objetivo reunir em um único lugar os trabalhos acadêmicos e projetos relacionados a:

- análise de dados abertos;
- visualização de informações;
- dashboard e relatórios;
- projetos de banco de dados e dados públicos;
- materiais complementares e imagens do processo de desenvolvimento.

---

## 📊 Projeto 1: Análise de Dados do PROCON

Este projeto tem como foco a análise de dados abertos do PROCON, com o objetivo de identificar padrões, tendências e informações relevantes sobre denúncias e conflitos de consumo.

### Objetivos
- Explorar e organizar os dados do PROCON;
- Visualizar informações em dashboard;
- Identificar regiões, categorias e recorrências nas denúncias;
- Transformar dados brutos em indicadores úteis para análise.

### Fonte dos dados
- Arquivo principal: `Procon-Dadosdenuncia.xlsx`

### Conteúdo relacionado
- imagens de dashboard;
- materiais de visualização;
- relatórios e evolução do projeto.

---

## 🛢️ Projeto 2: Petrobras e Gás Natural

Este conjunto de arquivos aborda dados de adesão ao decreto e dados do anuário estatístico da ANP, com foco em indicadores relacionados a Petrobras e gás natural.

### Conteúdo incluído
- `dados_petrobras_gas/README.md`
- `dados_petrobras_gas/adesao_decreto_1563_95.csv`
- `dados_petrobras_gas/anuario_estatistico_anp.csv`

### Principais temas
- adesão ao decreto 1563_95;
- distribuição temporal das adesões;
- dados de recursos, reusos e downloads;
- análise visual de séries e tendências.

---

## 🎨 Projeto 3: Apresentação no Canva

Também estão presentes materiais visuais de apresentação criativa, incluindo uma representação visual pessoal e de objetivos e interesses, desenvolvida em Canva.

### Objetivo
- apresentar de forma visual a identidade, interesses e objetivos pessoais;
- criar uma representação acadêmica e criativa do perfil do autor.
